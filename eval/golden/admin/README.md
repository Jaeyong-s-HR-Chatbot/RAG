# 관리자(hr_admin) 골든셋

결과 파일: [`../admin_golden_set.json`](../admin_golden_set.json) — 123문항 (질문셋 109 + 의도 경계 10 + 대화 기록 정책 4). 질문셋 '불가'(DB에 없는 데이터) 10문항은 2026-11-20에 뺌, 기준일 2026-11-09

## 만드는 법

```bash
python map_basis.py            # 규정 근거 글자 → 조문 ID (basis_map.json). 문서 이름만 있던 10문항은 사람이 보정
python build_admin_golden.py   # 질문셋 CSV + basis_map + labels_rule + DB/data CSV → admin_golden_set.json
```

질문셋 CSV나 DB 데이터가 바뀌면 `build_admin_golden.py`만 다시 돌리면 돼요. 집계 기대값은 백엔드 코드를 쓰지 않고 CSV에서 직접 계산해요.

## 정할 때 쓴 가정 (검수 필요)

- 기준일 2026-11-09 (데이터 생성 기준일). '올해·이번 달·다음 주'는 이 날짜 기준
- 연차수당 = 통상임금 ÷ 209 × 8 × 일수 (2026-10 급여의 통상임금)
- 퇴직금 평균임금은 최근 3개월 gross_pay ÷ 일수 근사 (성과급·연차수당 가산 미반영)
- 4급 시험승진 응시 대상 = 5급 3년 이상 (예정인원 배수는 DB에 없어 미반영)
- '자주'(지각 3회/3개월), '많이 남은'(복지포인트 30만), '오래'(같은 부서 5년)는 규정에 없어 가정값
- 장기근속수당 구간은 별표 12 기준(5·10·15·20·25년). rules.json의 가정값과 다름
- `uncertain` 6문항(20·34·66·67·77·101): 조문만으로 답이 확정되지 않거나 기준이 규정에 없음

## 대화 기록 정책 (2026-11-18 확정)

- 관리자는 챗봇 질문을 **주제별 건수로만** 볼 수 있음 (A-L01·L02, `chat_topic_stats`)
- 특정 직원의 질문(A-L03)·민감 상담자(A-L04) 조회는 거절. 설계도의 관리자 의도 세트에 `refuse` 추가 필요
- 대화 로그 데이터가 DB에 없어 기대값은 없음 (도구 선택·개인정보 비노출만 채점)
